# 営業担当者向け 使い方ガイド

営業担当者が見るのは **公式LINE** と **リマインド用の社内LINEグループ** の2つだけ。
管理画面を開く必要はない。

この文章はそのままLINEグループのノートに貼れるように書いてある。

---

## 1. これは何のしくみか

お客様から公式LINEにメッセージが届いたのに、**社内の誰も返信していない**とき、
社内グループに通知が出る。返信済みのものは通知されない。

目的はひとつ、**返信忘れをゼロにすること**。

---

## 2. 通知の見え方

### 初回（未返信 1時間）— ボタン付きで1件ずつ

```
⚠️ 未返信 1時間
山田太郎 様（担当：熊澤）
『内見の件ですが…』

返信したら下のボタンをタップしてください。
```

その下に2つのボタンが出る。

| ボタン | 押すと |
|---|---|
| ✅ 対応済みにする | そのお客様へのリマインドが止まる |
| 🙋 自分が担当にする | 自分がそのお客様の担当者になる |

### 2回目以降 — まとめて1通

```
⚠️ 未返信 3件（継続中）

🚨 佐藤花子 様 5時間20分（担当：未設定）
⚠️ 山田太郎 様 2時間（担当：熊澤）
⚠️ 鈴木一郎 様 1時間10分（担当：舛谷）
```

放置が長い順に並ぶので、**上から手を付ければよい**。
1件1通で送り続けると社内LINEが埋まって、かえって見落とすためこの形にしている。

### 印の意味

| 印 | 未返信の長さ |
|---|---|
| ⚠️ | 通常 |
| 🚨 | 3時間以上、または責任者にも通知が広がった |
| 🚨🚨 | 24時間以上 |

---

## 3. やること（これだけ）

1. 通知が来たら、公式LINEでお客様に返信する
2. **社内グループに戻って ✅ 対応済みにする を押す**

以上。

---

## 4. いちばん大事な注意点

### ⚠️ 公式LINEで返信しただけでは、リマインドは止まりません

LINEの仕様上、**公式LINEの管理画面から送った返信は、このシステムには届きません。**
システムから見ると「まだ誰も返信していない」ままなので、リマインドは鳴り続けます。

**返信したら、必ず ✅ を押してください。** これを忘れると通知が止まりません。

（逆に「返信していないのに ✅ を押す」のは絶対にやめてください。
そのお客様は以後リマインドされなくなり、放置に気づけなくなります。）

### ✅ は1往復ごとに押さなくてよくなりました

**✅ を押すと、そのお客様は3時間「対応中」になり、その間は鳴りません。**
お客様から返事が来ても鳴りません。やり取りが続いている最中に何度も押す必要はなく、
**1往復ごとに押し直さなくていい**ということです。

3時間たっても返信していなければ、普通にリマインドが鳴ります。
「対応中にしておけばもう安心」ではないので、そこは変わりません。

一覧で「🔇 対応中 17:00まで」と出ているお客様は、その時刻まで鳴りません。
早く監視に戻したいときは、隣の「監視に戻す」を押してください。

### 溜まったときは、まとめて対応済みにできます

未返信一覧で各行の**チェックボックス**を付けると、画面の下に
「✅ ○件を対応済みにする」が出ます。1件ずつ押さなくて済みます。

表の見出しのチェックボックスで、**表示中の分をまとめて選択**できます。

⚠️ **返信していないお客様を混ぜないでください。** まとめて閉じると、その人たちは
以後リマインドされません。選んだ相手に返信済みか、押す前に確認してください。
押すと一度確認が出るので、そこで止められます。

処理のあと「○件を対応済みにしました。△件は閉じられませんでした」と出ることがあります。
その△件は**まだ未返信のまま残っています**（他の人が先に操作した、または新しい
メッセージが届いた場合）。一覧を見直してください。

### まとめ通知にはボタンが付いていません

まとめ通知は複数のお客様が1通に入っているため、押し間違い防止でボタンを外しています。
止めたいときは、**そのお客様の最初の通知（ボタン付き）まで遡って ✅ を押してください。**
古い通知のボタンでも有効です。

### 「担当：未設定」が出たら

そのお客様にまだ担当者が付いていません。自分が見るなら 🙋 自分が担当にする を押してください。
担当が決まると、次回の通知から名前が入ります。

### ボタンを押しても反応がないとき

| 返ってきたメッセージ | 意味 |
|---|---|
| 「既に対応済みです」 | 誰かが先に押した。何もしなくてよい |
| 「この通知は古い未返信のものです」 | その後お客様から新しいメッセージが届いている。**新しい通知のほうを見て、改めて対応してください** |
| 「担当者として登録されていません」 | LINEアカウントが未連携。管理者に連携コードの発行を依頼してください |
| 何も返らない | 登録外のアカウント／グループから押している |

### 通知が来ない＝返信漏れがない、ではない場合がある

システム自体が止まると通知も出ません。その場合は
🛠【システム警告】 が管理者に飛ぶようになっています。
**長時間まったく通知が来ないのに問い合わせは来ている**というときは、管理者に一声かけてください。

---

## 5. 通知が出るタイミング

| | |
|---|---|
| 初回 | 未返信から 1時間後 |
| 2回目以降 | 1時間ごと（まとめて1通） |
| 営業時間外 | 通知しない。翌営業日の営業開始時刻まで繰り延べ |

お客様が続けてメッセージを送ってきた場合も、最長3時間で必ず通知が出ます。

※ 間隔・営業時間・文面は管理画面から変更できます。上は初期設定の値です。
