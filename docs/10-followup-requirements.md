# 10. 自動追客管理システム — 要件整理

## この機能の目的

不動産仲介では問い合わせ（反響）が多く、営業担当が追客しきれない顧客が大量に発生する。
このシステムの目的は **顧客管理を営業担当にさせないこと** にある。

> 営業担当が顧客管理をするのではなく、**システムが追客を管理し、営業担当には今日やるべき営業だけを提示する。**

営業担当に残す仕事は「話す・LINEする・電話する・提案する・内見する・申込を取る・成約する」だけ。
顧客情報の整理、追客日の管理、追客漏れの発見はシステム側の責務とする。

一般的なCRMではなく **追客漏れ防止システム** として設計している。
「顧客一覧を見せること」は目的ではない。ログインした瞬間に「今日、この顧客に何をすればいいか」が分かる状態を作る。

## 既存システム（公式LINE 未返信リマインド）との関係

このリポジトリには、先に作った **公式LINEの未返信リマインド** が入っている。
追客管理はそれを置き換えるものではなく、扱う時間軸が違う。

| | 未返信リマインド | 追客管理 |
|---|---|---|
| 見るもの | 顧客を待たせていないか | 追客が止まっていないか |
| 時間軸 | 分・時間 | 日・週 |
| 起動間隔 | 5分ごと | 1時間ごと |
| 画面 | `/reminders` | `/`（今日やること） |

両者は次の2点で接続している。

1. **顧客からLINEが届いたら**、追客ステータスを復活させ（返信なし・休眠・保留 → 初回対応済）、
   次回アクションを「返信する」にして優先度を S にする。
2. **管理画面からLINEを送ったら**、未返信リマインドが止まると同時に、追客の1手としても記録される。

「顧客を待たせている」状態は、どの追客ルールよりも優先される。
